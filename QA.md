## Limits

- Browser checks used Chrome with mobile emulation, not physical iOS/Android devices or Safari/Firefox.
- Personal photos and audio are not supplied; the included artwork is illustrative. Real photo/audio files still need content review before gifting.
- No GitHub repository or public deployment was created. The deployment workflow is configured but cannot be verified against the user's GitHub account until pushed and enabled there.
- Local checks ran on the machine's Node 23.7.0, which emits engine warnings for current lint/test tooling. All executed checks passed. The documented runtime, `.nvmrc`, and deployment workflow use supported Node 22 LTS (22.13+).
- `npm audit --omit=dev` reports **0 vulnerabilities**. The full audit reports **10 moderate development-only findings**, all tracing to a `minimatch` glob-processing advisory in lint tooling. No high or critical findings remain. The audit's suggested ESLint downgrade is incompatible with this modern config and was not applied. These tools are not shipped in the static website; use trusted project input when running them.
- A host npm 10 resolver error occurred during tooling updates. A temporary npm 11 resolver generated the clean lockfile; the host's standard `npm ci` then installed it successfully. No global npm installation was changed.

## Reproduce browser tests

```sh
npm ci
BASE_PATH=/anniversary/ SITE_URL=https://example.com/anniversary/ npm run build
npm run test:browser
npm run build
```

On non-macOS systems without the configured Chrome executable, first run `npx playwright install chromium`. The suite owns and stops its preview server. The final normal build restores relative asset paths for local previews.
